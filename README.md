# Exploiting Risk-Sensitive Strategies in Leduc Poker: CPT-Reweighted CFR and Explore-Then-Commit Agents

This repository contains the code for a thesis project studying how an opponent that deviates from Nash-equilibrium play in a risk-averse way can be detected and exploited in heads-up **Leduc Poker**, using [OpenSpiel](https://github.com/google-deepmind/open_spiel).

Two reference strategies are computed for the game:

1. **Standard CFR**: the classical Counterfactual Regret Minimization average policy, an approximate Nash equilibrium.
2. **CPT-CFR**: a "risk-averse" policy obtained by reweighting the CFR value computation with a Cumulative Prospect Theory (CPT) value function and probability-weighting function (Tversky & Kahneman, 1992). This produces a policy that deviates from expected-value-maximizing play, mimicking a loss-averse human opponent.

An **Explore-Then-Commit (ETC) agent** is then used to exploit a fixed opponent (CPT-CFR, standard CFR, or another exploration policy):

- **Exploration phase** (`m` hands): the ETC agent plays a fixed exploration policy while building an empirical model of the opponent's strategy at each information set.
- **Commit phase**: the agent computes a best response to the estimated opponent strategy (for both seating positions) and commits to it for the remainder of the match.

Three variants of the ETC agent are implemented and compared:

| Variant | Description |
|---|---|
| `ETCAgent` (V1) | No abstraction — every distinct information state string is tracked individually. |
| `ETCAgentV2` | Adds a **suit-irrelevance abstraction**: since suits don't matter strategically in Leduc, J♠/J♥, Q♠/Q♥, K♠/K♥ are merged in both the public history and the agent's own private card. This reduces the number of information sets that need to be estimated. |
| `ETCAgentV3` | Extends V2 with a **confidence threshold**: the empirical opponent action frequencies at an information set are only used once that state has been visited at least `threshold` times; below that, the agent falls back to a uniform prior. |

## Setup

The project requires Python 3.10+, [OpenSpiel](https://github.com/google-deepmind/open_spiel) and the libraries imported at the start of the notebook.

## Running the notebook

Open [`simulation.ipynb`](simulation.ipynb) in Jupyter. It is organized into the following sections:

1. **Imports** — loads OpenSpiel, plotting/data libraries, and the `leduc_poker` game.
2. **CFR-CPT Policy** — defines the CPT value function, the Tversky-Kahneman probability-weighting function, and a CPT-reweighted CFR loop. Computes the risk-averse policy (or load it directly from `cpt_cfr_policy.pkl`).
3. **CFR Policy** — computes the standard CFR average policy (or load it directly from `standard_cfr_policy.pkl`).
4. **Load CFR and CFR-CPT policies** — loads both pre-computed policies for use in later sections.
5. **Test Exploitability of Policies** — reports exploitability and best-response value for each policy.
6. **Agents** — defines `Bot` (samples actions from a fixed policy) and the `ETCAgent` / `ETCAgentV2` / `ETCAgentV3` exploiters.
7. **Simulation Function** — `run_simulation`, `simple_simulation`, `show`, and `compare` helpers for running repeated matches and plotting average return vs. exploration budget `m`.
8. **Simulations** — runs all experiments: ETC variants vs. CPT-CFR, different exploration strategies, ETC vs. standard CFR, and confidence-threshold ablations.
9. **Store data from each simulation** — appends per-repetition results to `simulation_results.csv`.

The cells that compute the CFR and CPT-CFR policies from scratch are clearly marked — they can be skipped by loading the corresponding `.pkl` files instead, since this is the slowest part of the notebook.

## Results

The [`plots/`](plots) directory contains the figures generated by the notebook, including:

- `ETC_vs_CFR.png`, `ETC_vs_CFR_large.png` — ETC agent performance against a standard CFR opponent, for small and large numbers of hands.
- `comparison_versions_ETC.png` — ETC V1 (no abstraction) vs. ETC V2 (suit-irrelevance abstraction).
- `comparison_ETC_uniform_vs_CFR.png` — uniform vs. standard-CFR exploration strategy for the ETC agent.
- `comparison_diff_threshold.png` — effect of the confidence threshold (ETC V3) on exploitation performance.
- `ETC_CFR_100k.png`, `ETC_uniform_100k.png`, `sim_ETC_CFR_10k.png`, `sim_ETC_no_simplification.png`, `sim_ETC_simplification_10k.png`, `etc_cfr_vs_cfr.png`, `comparison_100k.png` — additional results at different scales (10k / 100k hands per repetition).

`simulation_results.csv` contains the underlying per-repetition return data (overall and commit-phase returns) for every experiment, keyed by `simulation_name` and exploration budget `m_value`.
